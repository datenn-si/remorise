# プライバシーポリシー

最終更新日: 2026年11月18日

このプライバシーポリシー(以下「本ポリシー」)は、キャラクターチャットソフトウェア Remorise (以下「本ソフトウェア」)をユーザーが利用する際の情報の取り扱いについて定めるものです。

お問い合わせや GitHub での Issue, PR, Discussions などに対して本ポリシーは適用されません。

## 本ソフトウェアが収集しない情報

本ソフトウェアは利用者の個人情報を収集しません。アクセス解析、広告、トラッキング、テレメトリの送信は行いません。

会話、記憶、設定などのデータは、利用者の端末のデータディレクトリ内およびブラウザ内にのみ保存されます。これらのデータが、作者やコントリビューター及びその他第三者へ自動的に送信されることはありません。

データを消したい場合は、データディレクトリごと削除し、かつ接続先ドメインのデータをブラウザで消去してください。

## LLM API への送信

本ソフトウェアでの会話には、LLM API への接続が必要です。会話の内容や記憶の一部は、返答を生成するために、利用者が設定した接続先の API へ送信されます。

公式が想定している接続先は利用者自身の端末で動くローカル LLM ソフトウェアの API です。  
ローカル LLM ソフトウェアにおけるデータの取り扱いに関してはお使いの各ソフトウェアのドキュメントを確認してください。

外部の LLM プロバイダーが提供する API など、第三者が運営する API へ接続先をユーザーが変更した場合は、送信された情報はそのプロバイダーのプライバシーポリシーに従って取り扱われます。

接続先は利用者自身が設定するものであり、本ソフトウェアが接続先を勝手に変更することはありません。

## 他の端末からのアクセス

利用者がスマートフォンなどの他の端末から本ソフトウェアにアクセスする場合、その通信は利用者自身が用意した LAN や VPN (Tailscale など)を経由します。

VPN サービスなどを利用した際の通信の取り扱いに関してはお使いのサービスのドキュメントを確認してください。

これは利用者自身の端末同士の通信であり、本ソフトウェアが第三者へデータを送信するものではありません。

## ポリシーの変更

作者は必要に応じて本ポリシーを予告なく変更できます。

変更後のポリシーは公開した時点から効力を生じるものとします。
